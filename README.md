## 🚀 Featured Projects

### 1. GlucoAI — Diabetes Risk Prediction

A machine learning-based web application that predicts diabetes risk using patient health parameters.

**Tech Stack:** Python | Scikit-learn | Random Forest | Flask | Pandas

- Trained a Random Forest classification model on a dataset containing 100,000+ records.
- Applied data preprocessing and feature encoding.
- Used balanced class weights to address class imbalance.
- Developed a Flask web application for interactive predictions.
- Displays predicted risk probabilities and feature importance.

🔗 [View Project on GitHub](https://github.com/15Sarvagya/diabetes-risk-predictor)
